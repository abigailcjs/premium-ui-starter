---
description: Friendly orientation for someone brand new to coding using this starter pack.
---

Someone new to coding just opened this project. Give them a short, encouraging
orientation — no jargon, no walls of text. Assume they may have never run a
command before.

Cover, briefly and in this order:

1. **What this is** — a ready-made starter for building good-looking web apps, with
   a guided walkthrough so they make the look-and-feel decisions by clicking, not
   by reading docs.

2. **Get it running** (give exact commands, one per line, and say what each does):
   - `npm install` — downloads the building blocks (once).
   - `npm run dev` — starts the app, then open http://localhost:5173 in a browser.

3. **Design their UI** — on first run the **Setup Studio** pops up (or click the ✨
   wand, bottom-right). They pick fonts, color, corners and motion and hit Save.
   Mention they can also run `/setup` to do it together with you in chat.

4. **Where things live** (one line each): `src/App.tsx` is the page they edit,
   `src/components/ui/` are prebuilt pieces (buttons, cards), `src/studio/` powers
   the walkthrough.

5. **What to try next** — offer to make one small visible change with them (e.g.
   edit a heading in `src/App.tsx`) so they get a quick win.

End by asking what they'd like to build. Keep the whole reply scannable and kind.
