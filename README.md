# premium-ui-starter

A reusable, premium-grade UI starter — opinionated, official-first, and pre-wired to be driven by Claude Code. Clone it (or use it as a template) and start building polished React UI immediately.

## Stack

| Layer | Choice |
|---|---|
| Build | **Vite 8** (Rolldown) |
| Framework | **React 19** + **TypeScript** |
| Styling | **Tailwind v4** (`@tailwindcss/vite`) |
| Components | **shadcn/ui** — Nova preset, Radix base (you own the code) |
| Icons | **Lucide** |
| Animation | **Motion** + **GSAP** |
| Fonts | **Fontsource** — Geist (headings) / Inter (body) |

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173
```

Other scripts: `npm run build` (typecheck + production build), `npm run preview`, `npm run lint`.

## Use as a template

This is a GitHub **template repository** — click **"Use this template"**, or:

```bash
gh repo create my-app --template abigailcjs/premium-ui-starter --private --clone
```

## Conventions

- **Path alias:** `@/*` → `./src/*` (wired in `vite.config.ts` + `tsconfig`).
- **Fonts:** defined in `src/index.css` `@theme` — `--font-heading` = Geist, `--font-sans` = Inter; `h1–h6` use Geist automatically.
- **Components:** shadcn lands in `src/components/ui/`; config in `components.json`. Add more with `npx shadcn@latest add <name>`.
- **Theme tokens:** neutral OKLCH palette with light + dark, generated by shadcn (Nova).

## Claude Code integration

Built to be driven by Claude Code via the **`premium-ui`** orchestrator skill — describe the UI you want and it routes to the right design / motion / config skills and verifies in-browser.

- **MCP:** `shadcn` (project `.mcp.json` — approve the one-time trust prompt on first `claude` launch), plus global `Context7`, `chrome-devtools`, and `magic` (21st.dev).
- **Skill chain:** `premium-ui` (front door) → `frontend-design` + `impeccable` (taste) or `interface-design` (dashboards) → `emil-design-eng` + `gsap-*` (motion) → `tailwind-theme-builder` + `shadcn-ui` (config) → `baseline-ui` + `fixing-accessibility` + `fixing-motion-performance` (cleanup).

> Installed skills under `.agents/` are gitignored (reinstallable, not vendored).

## Project layout

```
src/

  lib/utils.ts     # cn() helper
  index.css        # Tailwind import + @theme tokens + fonts
  App.tsx          # smoke-test page (replace with your app)
```
